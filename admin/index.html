Configurações

Ficam salvas só neste aparelho. Faça uma vez em cada celular ou computador que for usar.

1. Publicação de artigos (GitHub) não conectado

  1. No GitHub, abra criar token.
  2. Nome: “Admin site”. Expiração: 1 ano. Em Repository access escolha Only select repositories e marque o repositório do site.
  3. Em Permissions → Contents escolha Read and write. Gere e cole o token abaixo.

2. Contador de visitas (GoatCounter, grátis)

  1. Crie a conta em goatcounter.com/signup usando o código brasilunitv.
  2. No painel dele, vá em Settings e marque “Allow adding visitor counts on your website”. Salve.
Se usar outro código, troque também no arquivo js/stats.js do site.

3. Google Search Console

  1. Adicione o domínio no Search Console (tipo “Domínio”) e envie o sitemap.xml.
  2. No Google Cloud, ative a Google Search Console API.
  3. Em APIs e serviços → Tela de consentimento OAuth, crie como “Externo” e adicione o Gmail do Paulo em “Usuários de teste”.
  4. Em Credenciais → Criar ID do cliente OAuth → Aplicativo da Web, coloque em “Origens JavaScript autorizadas” o endereço do site (com e sem www). Cole o ID abaixo.
